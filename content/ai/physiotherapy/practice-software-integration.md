# Practice Software Integration for Physiotherapy Clinics

Practice software integration is the layer that connects an AI system — receptionist, follow-up, recall — directly to the practice management platform a physiotherapy clinic already runs, such as WebPT, Cliniko, or Jane App, so scheduling and treatment-plan data stay in one place instead of being duplicated in a separate tool. It matters because physiotherapy scheduling is built around multi-session treatment plans, and a system that can't read a patient's actual plan progress creates more manual reconciliation work than it saves.

## How It Works
Input: Appointment, patient, and treatment-plan data from the practice management system via its API or integration layer
Processing: The AI system reads live scheduling and treatment-plan progress to make decisions, and writes outcomes back into the same system
Output: A practice management system that stays accurate and current, with no separate spreadsheet or side tool for staff to also maintain

## Use Cases
- Booking directly into real, live provider availability
- Pulling treatment-plan progress and discharge data straight from the practice system to drive follow-up and recall
- Writing call outcomes, confirmations, and notes back into the patient's record automatically
- Keeping multiple providers' schedules synced correctly across a busy multi-clinician clinic
- Avoiding the double data-entry problem that kills adoption of most bolt-on tools

## Benefits
- Eliminates the "two systems that don't talk to each other" problem that makes staff abandon new tools
- Keeps one system of record instead of fragmenting patient and treatment data across platforms
- Reduces scheduling errors caused by working from outdated or duplicated data
- Makes every other system (receptionist, follow-up, recall) actually usable day to day
